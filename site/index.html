Already have a deck.json?

The browser tool runs the same engine in this tab — check a deck, read every card, and export a real .apkg. Nothing to install, nothing uploaded. Useful if you run the method with your own agent and only want the checks and the export.

What it does

Point it at a folder of course material — slides as PDF, the transcript, the objectives — and pick an agent: any subscription agent from the public ACP registry (Claude, Gemini CLI, Codex and more), installed with one click and signed in through your browser, or any model through an OpenRouter key. It runs a three-step method: extract a fact inventory with verbatim sources, organize it into a card plan, write the cards. You review each artifact, flag cards in the preview, an independent auditor and adjudicator rule on what was flagged, and the deck exports as an .apkg or goes straight into Anki.

First launch

macOS: this is free software and the build is not notarized with Apple, so the first double-click says the app "cannot be opened". Open System Settings → Privacy & Security, scroll down, click Open Anyway. Once.
Windows: SmartScreen warns that the publisher is unknown. More info → Run anyway. Once.
Linux: mark the AppImage executable (chmod +x) or install the .deb.

Nothing leaves your machine except what you send the agent

No accounts, no server, no telemetry. Your course folder stays where it is; every artifact is written beside it. API keys go to your OS keychain. Updates are checked on launch and installed only when you click.
