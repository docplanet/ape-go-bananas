    Want to build a deck from lecture files?
    
    Get the desktop app: point it at a folder of course material, pick an agent you already pay for, and run the steps — extract, organize, cards, audit, export — reviewing each result before the next.
    
    
    The same thing runs inside this page against a bridge on your own machine, if you would rather not install the app:
    
    
      
    
    1. 
      
      Start the bridge
      
      
      In a terminal — with Node.js 20 or newer installed — run this, with your lecture folder in the quotes:
      
      
      npx -p github:docplanet/ape-go-bananas ape-bridge "/path/to/lecture folder"
      
      
      The first run builds the bridge, about a minute; after that it starts in a second. It listens on this computer only, and stops when you close the terminal.
      
    
      2. 
    
    2. 
      
      Open the link it prints
      
      
      That link is this page, attached to your bridge: the folder is filled in, you choose an agent — a Claude, Gemini or Codex subscription, or any model with an OpenRouter key — and run the steps in order. Each step's result is shown to you before the next.
