A.P.E.

Lecture files in, an Anki deck out. The work runs on your own computer, with an agent you already pay for; this page is the controls. Nothing is uploaded.

Runs here, in this tab — nothing installed, nothing uploaded. Sign in to an agent you already pay for, add your lecture files, and the deck is built on this page.

Or run it against your own machine, with the newest Claude Code

  1. Start the bridge

    In a terminal — with Node.js 20 or newer installed — run this, with your lecture folder in the quotes:

    npx -p github:docplanet/ape-go-bananas ape-bridge "/path/to/lecture folder"

    The first run builds the bridge, about a minute; after that it starts in a second. It listens on this computer only, and stops when you close the terminal.

  2. Open the link it prints

    That link is this page, attached to your bridge: the folder is filled in, you choose an agent — a Claude, Gemini or Codex subscription, or any model with an OpenRouter key — and run the steps in order: extract, organize, cards, audit, export. Each step's result is shown to you before the next.

Already have a deck.json? Check it and export the .apkg here — nothing to install.
